# THUK Studio

THUK Studio is a premium AI-powered creative agency website engineered with modern web technologies to deliver a fast, immersive, and visually engaging experience. The project combines cinematic animations, responsive layouts, and interactive 3D elements while maintaining high performance across devices.

**Live Website:** https://www.thuk.studio

---

## Overview

The website was redesigned from the ground up with a focus on:

- Modern UI/UX
- Smooth user interactions
- Responsive design
- Production-ready architecture
- High-performance rendering
- Interactive 3D experiences

---

## Key Features

- Premium landing page
- Responsive design for desktop, tablet, and mobile
- Interactive navigation
- Smooth scrolling experience

## Getting Started

Clone the repository

```bash
git clone https://github.com/Notinamood/thuk-studio.git
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
