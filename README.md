# THUK Studio

A premium AI-powered creative studio website built with Next.js, TypeScript, Tailwind CSS, Framer Motion, GSAP, and React Three Fiber.

## Features

- Premium cinematic UI
- Responsive design
- Interactive navigation
- GSAP-powered animations
- Smooth scrolling
- React Three Fiber integration
- Career page
- Contact section
- Showcase section
- Testimonials
- Services

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- React Three Fiber
- Drei

## Run locally

```bash
npm install
npm run dev
```
